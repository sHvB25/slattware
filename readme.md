  #Процесс

  2. Написал сам скрипт:

     /build.sh

    qemu-system-x86_64 -kernel kernel/7.2.8/arch/x86/boot/bzImage \
        -initrd initramfs.cpio.gz \
        -append "console=ttyS0" \
        -drive file=disk.img,if=virtio,format=raw -nographic 

  3. Обьясню, qemu-system-x86_64 -- это сам эмулятор (QEMU я думаю один из лучших)
     -kernel kernel/7.2.8/arch/x86/boot/bzImage -- путь к скомпилированому ядру
     -initrd initramfs.cpio.gz \ -- подключается временную файловую систему, проще говоря, подключется виртуальный диск, дабы избежать kernel panic
     -drive file=disk.img, if=virtio,format=raw -- подключает сам этот диск (тоесть в initrd его грубо говоря только загружают) в (сыром?) формате через интерфейс virtio
     -nographic без графики, отключает окно qemu
